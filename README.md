# Educación para la Paz

Sitio estático (HTML, CSS y JavaScript sin dependencias de compilación) para publicar en GitHub Pages.

## Vista local

Abra `index.html` directamente en un navegador, o sirva la carpeta `site` con cualquier servidor web estático. No requiere instalación de paquetes.

## Publicación en GitHub Pages

1. Cree un repositorio nuevo en GitHub y suba el contenido de esta carpeta (`index.html`, `styles.css`, `script.js` y `assets/`).
2. En el repositorio, abra **Settings** → **Pages**.
3. En **Build and deployment**, seleccione **Deploy from a branch**.
4. Elija la rama `main` y la carpeta `/(root)`; guarde los cambios.
5. GitHub mostrará la dirección pública del sitio cuando termine la publicación.

## Material y revisión

- El mapa mental está en `assets/mapa-mental-costa-rica.jpg`, extraído del documento base.
- No se incluyeron las imágenes sin atribución clara. El mapa mantiene su nota original de fuentes.
- Las referencias se presentan en orden alfabético, con doble espaciado y sangría francesa para su lectura en formato APA 7.
- La tipografía usa Google Fonts; si se desea una versión totalmente sin recursos externos, elimine las tres etiquetas de fuente de `index.html`. El sitio seguirá funcionando con fuentes del sistema.
